# Nosh

- This repository is forked version of the original repository. It serves as an
source code archive for personal purpose due to the disband of the original 
organization who made this project, which results the loss of the entire original 
repository, its Wikipedia, and design documentation.
- Due to the missing of original Wikipedia and design documentation, maintenance 
is paused permanently.

## What is Nosh?

- Nosh is a meal planning application available on Android platform.
- The main highlight of Nosh's features are the following:
    - Each user can manage (create, modify, delete) all information about 
    ingredient in his / her storage (amount, type, etc.)
    - Each user can manage all information about his / her recipes. Recipes can 
    include any ingredient whether if it's in a user's storage or not.
    - Each user can manage all information meal plans using his / her ingredient 
    in the storage and personal recipe.
    - Nosh is able to derived a grocery shopping list for missing ingredients 
    (either completely missing or missing a specific amount) from each user's 
    meal plan
